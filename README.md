## 🚀 Getting Started

Clone the repo and navigate to any problem folder:

```bash
git clone https://github.com/rahulgoswami/DSA-Cracker.git
cd DSA-Cracker/Question\ Bank/<Problem>/
```

Compile and run a C++ solution:

```bash
g++ -O2 -o solution solution.cpp
./solution
```

---

## 📌 Conventions

- Each problem lives in its own folder under `Question Bank/` or `POTD/`
- File names match the problem name in camelCase
- Every solution targets optimal time & space complexity
- SQL solutions use standard ANSI SQL compatible with MySQL / PostgreSQL
